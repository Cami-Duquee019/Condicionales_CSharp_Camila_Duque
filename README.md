# Ejercicios de condicionales en C#

Soluciones de los 30 ejercicios de lógica condicional. Cada ejercicio es un proyecto de consola independiente, desarrollado con .NET 10.

## Requisitos

- .NET 10 SDK

## Ejecutar un ejercicio

Desde la carpeta principal, ejecuta el proyecto deseado:

```powershell
dotnet run --project Problema04/Problema04.csproj
```

Reemplaza `Problema04` por la carpeta del ejercicio. Cada proyecto también incluye su descripción, ejemplo de uso y espacio para evidencias.
