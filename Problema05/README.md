# Problema 5: El mayor de dos números

Lee dos enteros, asigna el mayor a una variable usando una expresión condicional en una sola línea y lo imprime.

## Ejecución

```powershell
dotnet run --project Problema05/Problema05.csproj
```

Ejemplo: `14` y `9` producen `El mayor es 14`.
