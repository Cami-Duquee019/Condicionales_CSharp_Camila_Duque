# Problema 30: Boletín de calificaciones

Calcula el promedio de tres notas, asigna una letra (A: 90–100, B: 80–<90, C: 70–<80, D: 60–<70, F: <60), muestra la retroalimentación y determina aprobación desde 60. Un promedio exactamente igual a 100 agrega una mención de honor.

## Ejecución

```powershell
dotnet run --project Problema30/Problema30.csproj
```
