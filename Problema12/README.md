# Problema 12: Aprobación de crédito

Primero verifica si el solicitante tiene empleo. Sin empleo se rechaza el crédito; con empleo, un ingreso mensual desde $2.500.000 aprueba un crédito alto y un ingreso menor aprueba uno básico.

## Ejecución

```powershell
dotnet run --project Problema12/Problema12.csproj
```
