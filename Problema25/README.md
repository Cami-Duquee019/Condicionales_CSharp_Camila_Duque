# Problema 25: Calidad del aire

Asigna una categoría al ICA entero: Buena (0–50), Moderada (51–100), Dañina para grupos sensibles (101–150), Dañina (151–200) o Muy dañina (>200). Los valores negativos son inválidos.

## Ejecución

```powershell
dotnet run --project Problema25/Problema25.csproj
```
