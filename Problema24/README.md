# Problema 24: ¿Día hábil?

Clasifica los días numerados del 1 al 5 como `Día hábil` y los días 6 y 7 como `Fin de semana`. Cualquier otro número produce `Día inválido`.

## Ejecución

```powershell
dotnet run --project Problema24/Problema24.csproj
```
