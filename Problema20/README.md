# Problema 20: Días de cada mes

Indica el número de días de un mes de un año no bisiesto. Los meses se agrupan por duración; un número fuera del intervalo 1–12 se informa como inválido.

## Ejecución

```powershell
dotnet run --project Problema20/Problema20.csproj
```
