# Problema 1: Validación de edad para votar

Lee la edad de una persona y determina si puede votar. Con 16 años o más muestra `Puedes votar.`; con una edad menor muestra `No puedes votar aún.`.

## Ejecución

```powershell
dotnet run --project Problema01/Problema01.csproj
```

Ejemplo: al ingresar `18`, el resultado es `Puedes votar.`.
