# Problema 9: Año bisiesto

Determina si un año es bisiesto: debe ser divisible por 4 y no por 100, salvo que también sea divisible por 400.

## Ejecución

```powershell
dotnet run --project Problema09/Problema09.csproj
```

Ejemplos: `2024` y `2000` son bisiestos; `1900` no lo es.
