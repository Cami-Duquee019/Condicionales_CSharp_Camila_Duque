# Problema 13: Códigos de país

Convierte los códigos `CO`, `MX`, `AR`, `PE` y `CL` en sus nombres de país. Los códigos se aceptan sin distinguir mayúsculas y minúsculas; los demás se informan como no registrados.

## Ejecución

```powershell
dotnet run --project Problema13/Problema13.csproj
```
