# Problema 14: Estado del aprendiz

Lee una nota de 0 a 5 y asigna `Aprobado` si es igual o superior a 3,0, o `Reprobado` en caso contrario. El estado se determina en una sola asignación condicional.

## Ejecución

```powershell
dotnet run --project Problema14/Problema14.csproj
```
