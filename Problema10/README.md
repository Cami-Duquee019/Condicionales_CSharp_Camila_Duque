# Problema 10: Analizador de datos recibidos

Lee un valor y reconoce si representa un booleano, un entero, un decimal o texto. Imprime una descripción con su tipo y valor o, para el texto, su cantidad de caracteres.

## Ejecución

```powershell
dotnet run --project Problema10/Problema10.csproj
```

Ejemplos: `SENA` → `Texto de 4 caracteres`; `42` → `Entero: 42`; `true` → `Booleano: True`.
