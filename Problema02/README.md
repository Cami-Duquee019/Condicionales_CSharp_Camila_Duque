# Problema 2: Tarifa de envío según el peso

Calcula el costo de envío a partir del peso del paquete: más de 0 y menos de 1 kg cuesta $8.000; de 1 a 5 kg cuesta $15.000; más de 5 y menos de 20 kg cuesta $32.000; desde 20 kg cuesta $60.000. Un peso no positivo se informa como inválido.

## Ejecución

```powershell
dotnet run --project Problema02/Problema02.csproj
```
