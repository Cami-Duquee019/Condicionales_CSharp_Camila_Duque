# Problema 26: Peaje

Asigna la tarifa según el tipo de vehículo: M (moto, $0), A (automóvil, $12.000), B (bus, $25.000) o C (camión, $38.000). Una categoría no reconocida genera una excepción.

## Ejecución

```powershell
dotnet run --project Problema26/Problema26.csproj
```
