# Problema 21: Carrito de compras

Construye en una sola asignación el mensaje del carrito, usando `artículo` únicamente cuando la cantidad sea exactamente uno y `artículos` en los demás casos.

## Ejecución

```powershell
dotnet run --project Problema21/Problema21.csproj
```
