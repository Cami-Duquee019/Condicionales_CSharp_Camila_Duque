# Problema 6: Piedra, papel o tijera

Lee las jugadas de dos participantes y determina el ganador según las reglas de piedra, papel y tijera. Acepta las jugadas en mayúsculas o minúsculas e informa si hay empate o una jugada inválida.

## Ejecución

```powershell
dotnet run --project Problema06/Problema06.csproj
```

Ejemplo: `piedra` y `tijera` producen `Gana el jugador 1`.
