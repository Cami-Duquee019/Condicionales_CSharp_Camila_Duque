# Problema 22: Calculadora básica

Lee dos enteros y un operador (`+`, `-`, `*` o `/`), calcula y muestra la operación. La división entre cero y los operadores no soportados generan excepciones con los mensajes requeridos.

## Ejecución

```powershell
dotnet run --project Problema22/Problema22.csproj
```
