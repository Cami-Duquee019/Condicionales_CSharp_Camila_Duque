# Problema 15: Índice de masa corporal

Calcula el IMC como peso dividido por estatura al cuadrado y clasifica el resultado: bajo peso (<18,5), peso normal (<25), sobrepeso (<30) u obesidad. El IMC se imprime con un decimal.

## Ejecución

```powershell
dotnet run --project Problema15/Problema15.csproj
```
